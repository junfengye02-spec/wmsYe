## 基础库存功能

<a id="b01"></a>

### B01 设备资料管理

维护设备编码、名称、分类、单位、品牌、型号、规格及备注，支持新建、编辑和停用。

红框展示设备编码、名称、品牌、单位等资料，以及启用状态和保存入口。

![B01 设备资料管理：本机完整前端页面，红框标出功能区域](assets/screenshots/b01-device-records.jpg)

<a id="b02"></a>

### B02 仓库与库位管理

管理多层级存放地点，明确实际库位，支持查看本地点直属库存及包含下级地点的库存。

红框展示地点层级与库存入口，以及仓库名称、路径和库存项统计。

![B02 仓库与库位管理：本机完整前端页面，红框标出功能区域](assets/screenshots/b02-warehouse-locations.jpg)

<a id="b03"></a>

### B03 入库管理

记录入库设备、数量、所属项目、目标库位和经办人员，按配置完成审批后增加库存。

红框展示识别后的设备、项目、合同与质保信息，以及实际数量核对和加入草稿入口。

![B03 入库管理：本机完整前端页面，红框标出功能区域](assets/screenshots/b03-inbound.jpg)

<a id="b04"></a>

### B04 出库管理

按指定项目和实际库位办理出库，核对可用数量，记录出库用途、备注和经办人员。

红框展示项目与可用库存核对，以及出库用途、备注、数量和加入待出库入口。

![B04 出库管理：本机完整前端页面，红框标出功能区域](assets/screenshots/b04-outbound.jpg)

<a id="b05"></a>

### B05 库存查询

查看库存明细和设备汇总，区分实物库存、冻结数量与可用数量，支持多条件筛选。

红框展示关键字查询、设备种类与数量统计，以及合同、设备、库存和项目明细。

![B05 库存查询：本机完整前端页面，红框标出功能区域](assets/screenshots/b05-stock-query.jpg)

<a id="b06"></a>

### B06 库存盘点

上传 Excel 或 CSV 实盘数据，预览系统数量与实盘差异，确认后调整对应库存。

红框展示模板上传、盘点差异及整批确认入口。示例为系统数量 1、实盘数量 2、差额 +1；仅预览，未提交调整。

![B06 库存盘点：本机完整前端页面，红框标出功能区域](assets/screenshots/b06-stock-count.jpg)

<a id="b07"></a>

### B07 出入库记录

按日期、设备、项目和人员等条件查询出入库记录，统计业务数量并保留操作信息。

红框展示期间筛选、数量统计和已落账明细。示例查询到 1 条入库记录，数量合计 8。

![B07 出入库记录：本机完整前端页面，红框标出功能区域](assets/screenshots/b07-stock-history.jpg)

<a id="b08"></a>

### B08 数据导入导出

支持设备资料导入、库存初始化、盘点导入，以及库存明细、汇总和出入库记录导出。

红框展示导出按钮与导入菜单，可进入设备资料导入和库存盘点导入。

![B08 数据导入导出：本机完整前端页面，红框标出功能区域](assets/screenshots/b08-import-export.jpg)

<a id="b09"></a>

### B09 权限与追溯

按用户及角色控制查看、操作和审批权限，保留库存变动及人员操作记录。

红框展示审批组的角色权限矩阵与组名，区分查看、更改、添加和删除权限。

![B09 权限与追溯：本机完整前端页面，红框标出功能区域](assets/screenshots/b09-permissions.jpg)

## 二次开发功能

<a id="d01"></a>

### D01 扫码作业

扫码识别设备并自动带出资料，操作员核对数量后加入入出库申请，减少重复录入。

红框展示条码输入、自动带出的设备与项目合同信息，以及数量核对和加入申请入口。

![D01 扫码作业：本机完整前端页面，红框标出功能区域](assets/screenshots/d01-barcode-workbench.jpg)

<a id="d02"></a>

### D02 项目库存管理

建立统一项目档案，按设备、项目和实际库位区分库存，避免混扣其他项目的数量。

红框展示已有项目选择、新建项目入口及统一项目档案，供入库填单和库存归属选择使用。

![D02 项目库存管理：本机完整前端页面，红框标出功能区域](assets/screenshots/d02-projects.jpg)

<a id="d03"></a>

### D03 整单审批

多条明细统一提交，支持通过、驳回、撤销及超时处理，禁止自审，整单校验后落账。

红框展示整单完成状态、审批路由与时间线，以及实际到货 8 件的入库明细。顶部待入库数量为 0，表示已处理完成。

![D03 整单审批：本机完整前端页面，红框标出功能区域](assets/screenshots/d03-approval.jpg)

<a id="d04"></a>

### D04 出库冻结

出库明细加入申请即冻结对应可用库存；审批通过后扣减，驳回、撤销或超时后释放。

红框展示实物 1、冻结 1、可用 0，以及申请冻结数量和明细状态。截图后已撤销演示草稿，冻结已释放，未正式出库。

![D04 出库冻结：本机完整前端页面，红框标出功能区域](assets/screenshots/d04-stock-reservation.jpg)

<a id="d05"></a>

### D05 库存页面增强

在原生库存页面增加业务字段、筛选、设备汇总、分单位统计和全部匹配结果导出。

红框展示库存页新增的合同和质保字段，以及表格筛选面板中的业务筛选入口。

![D05 库存页面增强：本机完整前端页面，红框标出功能区域](assets/screenshots/d05-stock-filters.jpg)

<a id="d06"></a>

### D06 批量导入校验

上传后先预览再提交，错误整批拦截，防止重复执行及使用过期预览覆盖新库存。

红框展示负数盘点数量的校验错误。即使勾选核对确认，整批提交按钮仍不可用，错误数据无法落账。

![D06 批量导入校验：本机完整前端页面，红框标出功能区域](assets/screenshots/d06-import-validation.jpg)

<a id="d07"></a>

### D07 合同与质保管理

合同关联设备，统一维护验收日期、质保期限和到期日，支持查看当前质保信息。

红框展示已有合同、验收日期和质保月数，以及修改原因与影响数量核对入口。示例合同按 12 个月质保维护。

![D07 合同与质保管理：本机完整前端页面，红框标出功能区域](assets/screenshots/d07-contract-warranty.jpg)

<a id="d08"></a>

### D08 入库填单与完整标签

提前准备入库明细和完整二维码标签；扫码读取设备、项目及合同，核对后办理入库。

红框展示带有设备、项目和合同文字的完整标签，以及已保存入库单的准备数量、实际数量和标签操作入口。二维码保存明细标识与版本，扫码后由服务器读取业务信息；打印和补打不会增加库存。

![D08 入库填单与完整标签：本机完整前端页面，红框标出功能区域](assets/screenshots/d08-receipt-label.jpg)

<a id="d09"></a>

### D09 标签与本地打印

支持标签预览、逐项设置打印份数、选择本地打印队列、补打及 PDF 下载。

红框展示 PDF 下载、本机打印机选择和逐项打印份数。示例设置 2 张与 3 张，共 5 张；当前未连接打印组件，未执行实体打印。

![D09 标签与本地打印：本机完整前端页面，红框标出功能区域](assets/screenshots/d09-local-print.jpg)

本地队列提交成功仅表示任务已送入队列。Windows 驱动、标签纸尺寸、实物出纸和打印后扫码仍需按[现场验收交接](WINDOWS_LOCAL_PRINT_READY_FOR_WINDOWS.md)检查。

<a id="d10"></a>

### D10 安全与审计增强

防止重复入出库及并发超扣，保存审批信息、业务快照和库存变动前后数量。

红框展示扫码记录入口、关联申请与操作员、业务资料快照和变动前后数量。示例库存从 0 增至 8；并发与防重保护由后台逻辑执行。

![D10 安全与审计增强：本机完整前端页面，红框标出功能区域](assets/screenshots/d10-audit.jpg)
